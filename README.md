# MediTurno - Backend

API RESTful rápida y ligera construida para procesar solicitudes de turnos médicos y despachar notificaciones instantáneas.

# Tecnologías
* Lenguaje: Python
* Framework: FastAPI
* Integración: Telegram Bot API
* Despliegue: Render

# Características Principales
* Notificaciones Push: Conexión directa con Telegram para avisos inmediatos al personal de la clínica.
* Seguridad CORS: Accesos restringidos únicamente a los orígenes autorizados del frontend.
* Manejo de Errores: Respuestas HTTP claras para gestionar fallos de conexión o validación.
